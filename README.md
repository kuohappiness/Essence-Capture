# Essence Capture

Obsidian 外掛：可靠的知識入口。把課本、講義的 PDF 與圖片忠實轉錄成 Markdown，存進 vault 成為教材庫；之後再支援影片、網頁等來源。

> **規劃中**：還沒有可以使用的版本。

- 和 [Essence Cards](https://github.com/kuohappiness/Essence-Cards) 各自安裝、各自可用；有裝 Cards 時，轉錄完可以接著製卡。
- 轉錄稿的格式：[Essence Cards 的出題語法與資料格式 §1](https://github.com/kuohappiness/Essence-Cards/blob/main/docs/syntax.md#1-轉錄稿)。
- 規劃、決定與進度都寫在 Essence Cards 的 `docs/`（見 [AGENTS.md](AGENTS.md)）。
