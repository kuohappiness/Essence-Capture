# Essence Capture

Obsidian 外掛：可靠的知識入口。把課本、講義的 PDF 與圖片忠實轉錄成 Markdown，存進 vault 成為教材庫；之後再支援影片、網頁等來源。

> **規劃中**：還沒有可以使用的版本。

- 和 [Essence Cards](https://github.com/kuohappiness/Essence) 各自安裝、各自可用；有裝 Cards 時，轉錄完可以接著製卡。
- 轉錄稿的格式：[Essence Cards 的出題語法與資料格式 §1](https://github.com/kuohappiness/Essence/blob/main/docs/syntax.md#1-轉錄稿)。
- 開發在 [Essence](https://github.com/kuohappiness/Essence) repo 的 [`plugins/capture/`](https://github.com/kuohappiness/Essence/tree/main/plugins/capture)，規劃、決定與進度也寫在那裡；這個 repo 之後放發布檔，現在不放程式（見 [AGENTS.md](AGENTS.md)）。
